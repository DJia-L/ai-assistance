## 组件设计原则

### 单一职责

每个组件应专注于单一功能，避免过于复杂的多功能组件。当组件代码超过300行时，应考虑拆分为多个小组件。

### 可复用性

组件设计应当考虑复用场景，提取通用逻辑和UI模式，避免代码重复。

### 可配置性

组件应提供适当的配置项，允许调用方自定义外观和行为。

### 可测试性

组件应便于编写单元测试，避免直接依赖外部环境和全局状态。

### 可访问性

组件应遵循Web可访问性标准(WCAG)，确保所有用户都能使用系统功能。

## 命名规范

### 文件命名

- 组件文件名使用 **PascalCase**（首字母大写的驼峰式）：`Button.tsx`, `UserProfile.tsx`
- 工具函数文件使用 **camelCase**（首字母小写的驼峰式）：`utils.ts`, `hooks.ts`
- 样式文件使用 **camelCase**：`styles.ts`, `buttonStyles.ts`

### 组件命名

- React组件名使用 **PascalCase**：`Button`, `UserProfile`
- 组件Props接口名使用组件名+Props：`ButtonProps`, `UserProfileProps`
- Styled Components名称使用 **Styled** 前缀：`StyledButton`, `StyledUserProfile`

### 变量命名

- 变量和函数使用 **camelCase**：`userName`, `handleSubmit`
- 常量使用 **UPPER_SNAKE_CASE**：`MAX_RETRY_COUNT`, `API_ENDPOINT`
- 布尔值变量使用 **is/has/should** 等前缀：`isLoading`, `hasError`, `shouldRefresh`

### 事件处理函数

- 命名模式为 **handle + 事件名**：`handleClick`, `handleSubmit`, `handleInputChange`

## 样式开发

本项目使用 **styled-components** 进行样式开发，遵循如下规范：

### 样式定义位置

- 简单组件的样式可直接定义在组件文件中
- 复杂组件的样式应放在独立的 `styles.ts` 文件中

### 样式命名

```tsx
// 推荐
const StyledButton = styled.button``;
const StyledHeader = styled.header``;

// 避免
const Button = styled.button``;   // 与React组件名冲突
const ButtonStyled = styled.button``;  // 后缀不统一
```

### 主题使用

始终从主题对象中获取颜色、字体等样式变量，避免硬编码值：

```tsx
// 推荐
const StyledButton = styled.button`
  background-color: ${props => props.theme.colors.primary};
  color: ${props => props.theme.colors.white};
  font-size: ${props => props.theme.fontSizes.medium};
`;

// 避免
const StyledButton = styled.button`
  background-color: #3B82F6;  // 硬编码颜色
  color: white;
  font-size: 16px;  // 硬编码尺寸
`;
```

### 响应式设计

使用主题中定义的断点进行响应式设计：

```tsx
const StyledComponent = styled.div`
  padding: 1rem;
  
  // 使用主题断点
  @media (max-width: ${props => props.theme.breakpoints.md}) {
    padding: 0.5rem;
  }
`;
```

## TypeScript规范

### Props类型定义

始终为组件定义Props接口：

```tsx
interface ButtonProps {
  variant?: 'primary' | 'secondary' | 'text';  // 枚举类型
  size?: 'small' | 'medium' | 'large';
  disabled?: boolean;
  onClick?: (event: React.MouseEvent<HTMLButtonElement>) => void;  // 事件处理函数
  children: React.ReactNode;  // 子元素
}

export const Button: React.FC<ButtonProps> = ({ 
  variant = 'primary',
  size = 'medium',
  disabled = false,
  onClick,
  children 
}) => {
  // 组件实现
};
```

### 状态类型

为useState明确指定类型：

```tsx
// 推荐
const [isLoading, setIsLoading] = useState<boolean>(false);
const [user, setUser] = useState<User | null>(null);

// 避免
const [isLoading, setIsLoading] = useState(false);  // 可以推导，但显式更好
const [user, setUser] = useState(null);  // 无法推导具体类型
```

### 事件类型

使用正确的React事件类型：

```tsx
// 点击事件
const handleClick = (event: React.MouseEvent<HTMLButtonElement>) => {
  // 处理点击
};

// 表单提交
const handleSubmit = (event: React.FormEvent<HTMLFormElement>) => {
  event.preventDefault();
  // 处理提交
};

// 输入变化
const handleChange = (event: React.ChangeEvent<HTMLInputElement>) => {
  // 处理输入变化
};
```

## 组件编写模式

### 函数组件

使用函数组件和Hooks，避免使用类组件：

```tsx
// 推荐
export const UserProfile: React.FC<UserProfileProps> = ({ userId }) => {
  const [user, setUser] = useState<User | null>(null);
  
  useEffect(() => {
    // 获取用户数据
  }, [userId]);
  
  return (
    <div>{user ? user.name : 'Loading...'}</div>
  );
};

// 避免使用类组件
class UserProfile extends React.Component<UserProfileProps, UserProfileState> {
  // 类组件实现
}
```

### 条件渲染

使用逻辑运算符或三元表达式进行条件渲染：

```tsx
// 使用逻辑与
return (
  <div>
    {isLoading && <Spinner />}
    {error && <ErrorMessage message={error} />}
    {user && <UserInfo user={user} />}
  </div>
);

// 使用三元表达式
return (
  <div>
    {isLoading ? <Spinner /> : user ? <UserInfo user={user} /> : <EmptyState />}
  </div>
);
```

### 列表渲染

使用map渲染列表时，务必提供key属性：

```tsx
// 推荐
return (
  <ul>
    {items.map(item => (
      <li key={item.id}>{item.name}</li>
    ))}
  </ul>
);

// 避免
return (
  <ul>
    {items.map((item, index) => (
      <li key={index}>{item.name}</li>  // 尽量避免使用索引作为key
    ))}
  </ul>
);
```

## 状态管理

### 组件内状态

对于组件内部状态，使用useState或useReducer：

```tsx
// 简单状态
const [count, setCount] = useState(0);

// 复杂状态
const [state, dispatch] = useReducer(reducer, initialState);
```

### 数据获取

使用自定义hook封装数据获取逻辑：

```tsx
// hooks/useUserData.ts
export const useUserData = (userId: string) => {
  const [user, setUser] = useState<User | null>(null);
  const [loading, setLoading] = useState<boolean>(true);
  const [error, setError] = useState<string | null>(null);
  
  useEffect(() => {
    const fetchUser = async () => {
      try {
        setLoading(true);
        const data = await getUserData(userId);
        setUser(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };
    
    fetchUser();
  }, [userId]);
  
  return { user, loading, error };
};

// 组件中使用
const UserProfile: React.FC<{ userId: string }> = ({ userId }) => {
  const { user, loading, error } = useUserData(userId);
  
  if (loading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;
  
  return <div>{user.name}</div>;
};
```

## 性能优化

### 避免不必要的渲染

使用React.memo、useCallback和useMemo避免不必要的渲染：

```tsx
// 使用React.memo
const MemoizedComponent = React.memo(Component);

// 使用useCallback
const handleClick = useCallback(() => {
  // 处理点击
}, [dependency]);

// 使用useMemo
const expensiveCalculation = useMemo(() => {
  return computeExpensiveValue(a, b);
}, [a, b]);
```

### 懒加载

对于大型组件或不是首屏渲染的组件，使用懒加载：

```tsx
const LazyComponent = React.lazy(() => import('./HeavyComponent'));

const App = () => {
  return (
    <React.Suspense fallback={<Spinner />}>
      <LazyComponent />
    </React.Suspense>
  );
};
```

## 组件测试

使用React Testing Library进行组件测试：

```tsx
// Button.test.tsx
import { render, screen, fireEvent } from '@testing-library/react';
import Button from './Button';

describe('Button', () => {
  it('renders button with text', () => {
    render(<Button>Click me</Button>);
    expect(screen.getByText('Click me')).toBeInTheDocument();
  });
  
  it('calls onClick when clicked', () => {
    const handleClick = jest.fn();
    render(<Button onClick={handleClick}>Click me</Button>);
    fireEvent.click(screen.getByText('Click me'));
    expect(handleClick).toHaveBeenCalledTimes(1);
  });
  
  it('is disabled when disabled prop is true', () => {
    render(<Button disabled>Click me</Button>);
    expect(screen.getByText('Click me')).toBeDisabled();
  });
});
```

 */

  // 实现
};
```
