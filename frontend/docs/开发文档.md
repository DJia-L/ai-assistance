## 项目概述

融媒体AI助手系统是基于DeepSeek大模型构建的专业内容创作工具，旨在帮助媒体工作者提高内容创作效率和质量。系统提供智能对话、稿件分析、内容生成、热点话题挖掘等多种功能，实现融媒体内容的全流程智能化管理。

### 特点

- 多模型AI对话（DeepSeek通用AI、AI小融、AI小秘）
- 知识库增强的智能问答
- 媒体稿件智能分析
- 热点话题分析与挖掘
- 内容智能生成与优化
- 跨平台内容分发策略
- 语音交互能力

## 技术架构

### 前端技术栈

- **框架**：Next.js (React)
- **语言**：TypeScript
- **UI组件**：Ant Design
- **样式解决方案**：Styled Components

## 安装与运行

### 环境要求

- Node.js 16.x 或更高版本
- npm 7.x 或更高版本
- 现代浏览器（Chrome, Firefox, Edge等）

### 安装步骤

1. 克隆代码仓库

```bash
git clone [仓库地址]
cd media-ai-assistant-frontend
```

2. 安装依赖

```bash
npm install
```

3. 配置环境变量

创建`.env.local`文件，添加以下配置：

```
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
NEXT_PUBLIC_AUTH_ENABLED=true
```

4. 启动开发服务器

```bash
npm run dev
```

5. 构建生产版本

```bash
npm run build
npm start
```

## 功能模块

### 1. AI对话模块

支持多种AI模型的智能对话，包括DeepSeek通用模型、AI小融和AI小秘。用户可以通过文本或语音与AI进行交互，获取智能回答。

**关键组件**：
- `pages/chat.tsx` - 对话页面
- `components/AIDialog/` - 对话相关组件

**主要功能**：
- 多模型切换
- 对话历史管理
- 知识库增强问答
- 语音交互

### 2. 稿件分析模块

分析媒体稿件的内容、热度、传播价值，提供数据分析和优化建议。

**关键组件**：
- `pages/article-analysis.tsx` - 稿件分析页面
- `components/ArticleAnalysis/` - 分析相关组件

**主要功能**：
- 稿件内容分析
- 传播数据统计
- 优化建议

### 3. 智能编辑模块

提供内容创作、编辑和优化功能，帮助用户生成高质量的融媒体内容。

**关键组件**：
- `pages/smart-editing.tsx` - 智能编辑页面

**主要功能**：
- 内容生成
- 排版优化
- 内容校对

### 4. 热点话题模块

分析当前热门话题，提供话题挖掘和内容创作方向建议。

**关键组件**：

## API接口

系统通过`src/config/api.ts`中定义的API接口与后端服务交互。

### 核心API接口

```typescript
export const API_BASE_URL = 'http://localhost:8000';

export const API_ENDPOINTS = {
    AIDialog: `${API_BASE_URL}/api/ai-dialog`,
    AIVoice: `${API_BASE_URL}/api/ai-dialog/voice`,
    ArticleAnalysis: `${API_BASE_URL}/api/article-analysis`,
    HotTopics: `${API_BASE_URL}/api/hot-topics`,
    VideoScript: `${API_BASE_URL}/api/video-script`
};
```

### API调用示例

```typescript
// 发送消息到AI对话服务
export const sendMessage = async (
  userId: string,
  messages: ChatMessage[],
  model: string = 'deepseek',
  useKnowledgeBase: boolean = false,
  kbId?: string
) => {
  try {
    const response = await axios.post(`${API_ENDPOINTS.AIDialog}/send-message`, {
      user_id: userId,
      messages: messages.map(msg => ({
        role: msg.role,
        content: msg.content
      })),
      model,
      use_knowledge_base: useKnowledgeBase,
      kb_id: kbId
    });
    return response.data;
  } catch (error) {
    console.error('发送消息失败:', error);
    throw error;
  }
};
```

## 开发指南

### 添加新页面

1. 在`src/pages`目录下创建新的页面文件，如`new-feature.tsx`
2. 基本页面结构：

```tsx
import React from 'react';
import Head from 'next/head';

export default function NewFeaturePage() {
  return (
    <>
      <Head>
        <title>新功能 | 融媒体AI助手</title>
      </Head>
      <div className="container">
        {/* 页面内容 */}
      </div>
    </>
  );
}
```

### 添加新组件

1. 在`src/components`目录下创建新的组件文件或目录
2. 基本组件结构：

```tsx
import React from 'react';
import styled from 'styled-components';

const StyledComponent = styled.div`
  /* 组件样式 */
`;

interface ComponentProps {
  // 组件属性
}

export const Component: React.FC<ComponentProps> = (props) => {
  return (
    <StyledComponent>
      {/* 组件内容 */}
    </StyledComponent>
  );
};
```

### 添加新API接口

1. 在`src/config/api.ts`中添加新的API端点
2. 在`src/utils/api.ts`中添加新的API调用函数

```typescript
// 在config/api.ts中添加
export const API_ENDPOINTS = {
  // 现有端点
  NewFeature: `${API_BASE_URL}/api/new-feature`,
};

// 在utils/api.ts中添加
export const callNewFeatureApi = async (params) => {
  try {
    const response = await axios.post(API_ENDPOINTS.NewFeature, params);
    return response.data;
  } catch (error) {
    console.error('调用新功能API失败:', error);
    throw error;
  }
};
```

### 样式开发规范

推荐使用Styled Components进行样式开发，保持组件样式的隔离性。对于全局样式，可以在`src/styles`目录下定义。

```tsx
// 组件样式示例
const Button = styled.button`
  background-color: ${props => props.theme.colors.primary};
  color: white;
  padding: 8px 16px;
  border-radius: 4px;
  
  &:hover {
    background-color: ${props => props.theme.colors.primaryDark};
  }
`;
```

### 代码提交规范

提交代码时，请遵循以下规范：

- **feat**: 新功能
- **fix**: 修复bug
- **docs**: 文档变更
- **style**: 代码格式（不影响代码运行的变动）
- **refactor**: 重构（即不是新增功能，也不是修改bug的代码变动）
- **perf**: 优化相关，如提升性能、体验
- **test**: 测试相关
- **chore**: 构建过程或辅助工具的变动

示例：`feat: 添加用户画像分析功能`

## 常见问题

### 1. 如何处理API请求错误？

系统使用Axios拦截器统一处理API请求错误。在需要自定义错误处理的地方，使用try/catch块捕获特定错误。

```typescript
try {
  const response = await sendMessage(userId, messages, selectedModel);
  // 处理成功响应
} catch (error) {
  if (axios.isAxiosError(error)) {
    if (error.response?.status === 401) {
      // 处理未授权错误
    } else {
      // 处理其他错误
    }
  } else {
    // 处理非Axios错误
  }
}
```

### 2. 如何添加新的AI模型？

1. 在`src/types/chat.ts`中添加新的模型类型
2. 在对话页面中添加模型选择选项
3. 在API调用时传递正确的模型参数

### 3. 开发环境与生产环境的区别？

开发环境使用`.env.local`文件中的配置，生产环境应该使用环境变量或部署平台提供的配置机制。确保敏感信息不要硬编码在代码中。
