# 融媒体AI助手系统

基于DeepSeek大模型的媒体助手系统，提供全方位的融媒体内容分析、生成与优化服务。

## 核心功能
1. **AI对话**：支持多种AI模型的语音和文本交互，包括：DeepSeek：通用AI对话能力
    AI小融：基于DeepSeek增强，集成公有知识库，提供单位内融媒体信息查询
    AI小秘：基于DeepSeek增强，集成用户私有知识库，为用户提供个性化计划、规划制定
2. **稿件分析**：统计媒体员工稿件产出数量、热度、传播值，各平台数据分析
3. **AI配音**：根据用户音频训练AI自定义配音
4. **旅游娱乐导览**：以可互动的3D地图模式展现地方旅游和娱乐资源
5. **内容生产**：文档内容生排版、校对工具



## 技术架构

- **前端**：React + TypeScript + Next.js
- **后端**：Python + FastAPI
- **AI模型**：DeepSeek API集成
- **数据库**：PostgreSQL + Redis
- **移动端**：React Native
- **数据分析**：Pandas + PyTorch + Scikit-learn

## 设计风格规范

### 品牌标识

- **Logo**: "AI Media Integration" + "融媒体AI助手系统"
- **AI字样**: 使用DeepSeek风格的渐变色效果（蓝色到绿色）
- **色彩方案**: 主色调为DeepSeek蓝色(#3B82F6)与辅助绿色(#10B981)

### 色彩系统

- **主色**: #3B82F6 (蓝色)
- **辅助色**: #10B981 (绿色)
- **文本色**:
  - 主要文本: rgba(255, 255, 255, 0.95)
  - 次要文本: rgba(255, 255, 255, 0.7)
  - 深色文本: #333333
- **背景色**:
  - 深色背景: #111111
  - 浅色背景: #fafafa
  - 卡片背景: rgba(255, 255, 255, 0.15)
- **功能色**:
  - 成功: #10B981
  - 警告: #FBBF24
  - 错误: #EF4444
  - 信息: #3B82F6

### 字体系统

- **主要字体**: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
- **字重**:
  - 轻量: 300
  - 常规: 400
  - 中等: 500
  - 半粗: 600
  - 粗体: 700

### 组件规范

1. **Logo组件**:
   - 统一的品牌展示
   - 支持不同尺寸和组合

2. **按钮组件**:
   - 主要按钮: 渐变蓝绿背景
   - 次要按钮: 纯色背景
   - 轮廓按钮: 有边框无背景
   - 文本按钮: 无边框无背景

3. **导航栏**:
   - 固定在顶部
   - 透明/半透明效果
   - 响应式设计

4. **卡片组件**:
   - 半透明背景
   - 轻微阴影
   - 悬停效果

### 布局规范

- 使用响应式设计
- 页面内容区域最大宽度为1400px
- 页面间距使用统一的间距系统

### 交互规范

- 按钮、链接等元素需提供悬停状态反馈
- 表单提交、数据加载等操作需提供加载状态
- 错误信息需明确展示
